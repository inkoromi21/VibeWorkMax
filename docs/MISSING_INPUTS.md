# Реестр отсутствующих входных данных

## Как использовать

Это рабочий checklist тимлида для разработки, пилота, production и конкурсной сдачи. В реестре нет значений секретов, credentials, доменов, URL или внешних идентификаторов. Разрешённые значения `status`: `не начато`, `ожидается`, `частично`, `получено`, `не требуется`, `блокировано`.

Сроки указаны как проверяемые гейты, потому что календарные даты не предоставлены. Владелец продукта должен заменить гейт календарной датой, когда будет известен график. Локальные fallback не являются production-готовностью и должны явно показываться как mock, demo, disabled mode или local adapter.

Колонки `env` содержат только имена переменных окружения. Значения передаются через одобренное секрет-хранилище или защищённый канал вне репозитория, документации, задач и логов.

## MAX

Проверка `GET /me` с имеющимся токеном пока не подтверждена: TLS-клиент отклоняет цепочку `platform-api2.max.ru` с `UNABLE_TO_GET_ISSUER_CERT_LOCALLY`. Проверку сертификата отключать нельзя. Deployment owner должен получить и проверить корневой `Russian Trusted Root CA` из утверждённого источника, передать путь к PEM через `NODE_EXTRA_CA_CERTS` до запуска Node.js и повторить read-only проверку `node --env-file=.env scripts/check-max-connection.mjs`. Скрипт не печатает токен или идентификатор бота. Для `message_created` и `message_callback` локально настроен режим `MAX_PROVIDER_EVENT_ID_FIELD=event_specific`: он использует документированные `message.body.mid` и `callback.callback_id`. Другие события, включая `bot_started`, остаются закрытыми в enabled-режиме до подтверждения стабильного ID; внешний smoke ещё не выполнен.

## S3

Основной Docker-профиль запускает API с `S3_MODE=disabled`: загрузка вложений остаётся закрытой без сканера. Для конкурсного локального режима добавлен private filesystem adapter (`S3_MODE=local`, абсолютный `ATTACHMENT_LOCAL_DIR`) и проверка ClamAV: неподтверждённый файл остаётся в карантине, заражённый удаляется, чистый выпускается. Без настроенного сканера файл не считается принятым. Необязательный профиль `storage` пока не является приёмочным: закреплённый образ MinIO недоступен из реестра в проверенной среде 29.09.2026. Перед production-включением файлов нужно выбрать и проверить поддерживаемый S3-сервис/образ, настроить ClamAV и провести отдельный upload → quarantine → scan → release smoke.
